📖 Overview

The DIY Fighter Helicopter Model (Arduino-Based) is a hardware project that demonstrates the design and construction of a realistic fighter helicopter model using Arduino electronics. The project combines mechanical design, electronics, and programming to create a functional prototype with a rotating main rotor and navigation LEDs.

This project was built for learning purposes to improve practical skills in hardware design, circuit assembly, Arduino programming, and project documentation.

---

✨ Features

- 🚁 Realistic fighter helicopter body
- ⚙️ Arduino-based control system
- 🔄 Rotating main rotor using DC motor
- 💡 Red and green navigation LEDs
- 🔋 Battery-powered operation
- 🛠️ Lightweight handcrafted structure
- 📚 Complete project documentation
